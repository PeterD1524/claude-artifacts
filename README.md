# Claude Artifacts for coding agents

This repository holds a draft [integration design](SPEC.md), a separate [Anthropic Artifacts API reference](api/README.md), and [preserved artifact-related Claude skills](skills/README.md). It contains no integration program. The goal is to specify how a coding agent can publish Claude-hosted artifacts, keep them updated, and handle comments and session notifications.

The Claude frame protocol is private and subject to change. The spec separates proposed requirements from observed service behavior and identifies the portions that still require end-to-end verification.
