# Claude artifact skills

Each directory contains a `SKILL.md` and its supporting material:

* [Artifact design](artifact-design/SKILL.md) — design guidance; [additional guidance](artifact-design/references/claude-code-2.1.318.md).
* [Artifact capabilities](artifact-capabilities/SKILL.md) — runtime capabilities; [additional guidance](artifact-capabilities/references/claude-code-2.1.303.md). The [0.2.91](artifact-capabilities/0.2.91/) and [0.2.87](artifact-capabilities/0.2.87/) directories contain the corresponding versioned type definitions.
* [Artifact diagramming](artifact-diagramming/SKILL.md) — diagramming guidance; [additional guidance](artifact-diagramming/references/claude-code-2.1.314.md).

References to type definitions are relative to the relevant skill directory. Capability contracts and tool names can change; check the live contract for current behavior.

These skills cover page authoring and runtime capabilities. The [frame API specification](../api/README.md) describes a separate interface. Some guidance is available in the [community skill archive](https://github.com/asgeirtj/system_prompts_leaks/tree/bb7bbddf377c8d82c56f533134c6b93f13d245ae/Anthropic/claude-code/skills), which declares CC0; that metadata does not establish authorship of the captured text.
